About The Project

Project Overview

AI-Based Text Summarization System using Transformer-based Natural Language Processing is an advanced MCA final-year project that provides intelligent document summarization capabilities.

The system converts lengthy documents into concise, coherent, and meaningful summaries while preserving essential information using both extractive and abstractive techniques.

Methodology
1. Extractive Summarization (TextRank)

Uses graph-based ranking algorithm where sentences are treated as nodes and similarity scores as edges. PageRank algorithm ranks sentences to extract most important ones.

2. Abstractive Summarization (BART Transformer)

Uses pre-trained Bidirectional and Auto-Regressive Transformers (BART) model from Hugging Face to generate paraphrased, human-like summaries by understanding context.

3. Document Processing

Supports PDF (PyMuPDF), DOCX (python-docx), TXT files, and web article extraction using BeautifulSoup with security measures.
